# Прототип палитры — текст и заливка

Интерактивный прототип для оценки двух палитр (Вариант 1 / Вариант 2) в светлой и тёмной темах. Две таблицы 7×7: первая показывает цвет текста, вторая — цвет заливки. Под каждой таблицей — статистика покрытия WCAG (AA 4.5+, AA-lg, FAIL).

## Как запустить

Дважды кликните по `index.html` — откроется в браузере. Интернет нужен (подгружаются React и Babel с unpkg).

Если хотите без интернета — скачайте и положите рядом эти три файла, затем замените в `index.html` пути:

- https://unpkg.com/react@18/umd/react.production.min.js → `react.js`
- https://unpkg.com/react-dom@18/umd/react-dom.production.min.js → `react-dom.js`
- https://unpkg.com/@babel/standalone/babel.min.js → `babel.min.js`

## Файлы

- `index.html` — **главный файл**, запускается самостоятельно
- `app.jsx` — исходный React-компонент (для редактирования)
- `styles.css` — базовые стили

Если вы правите `app.jsx` или `styles.css`, нужно перегенерировать `index.html` — проще всего встроить их содержимое в тег `<script type="text/babel">` и `<style>` соответственно.

## Что умеет

- **Переключение темы** — меняет фон страницы и дефолтный цвет текста
- **Переключение варианта палитры** — меняет цвета в обеих таблицах и в пикере
- **Клик по ячейке** → выбор цвета текста или заливки через пикер 7×7
- **«Сбросить всё»** — возврат обеих таблиц к дефолтному состоянию
- **«Показывать FAIL»** — красная рамка вокруг ячеек с контрастом < 3.0
- **Статистика** под каждой таблицей пересчитывается автоматически

## Формат хранения цветов

Ячейки помнят не конкретный HEX, а **слот** в палитре (`{row, col}`). При переключении темы или варианта HEX'ы резолвятся автоматически из актуальной палитры — сохраняется семантика выбора.
